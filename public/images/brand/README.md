# Brand Assets

This folder contains Sivara Solutions brand assets.

## Logo Files

Place your logo files here:

- `logo.svg` - Primary logo (SVG format recommended for scalability)
- `logo.png` - PNG fallback (recommended: 500x500px or larger)
- `logo-white.svg` - White version for dark backgrounds
- `logo-white.png` - White PNG fallback

## Usage

The logo will be displayed in:
- Header/Navigation (if added)
- Footer
- Favicon (converted from logo)

## Recommended Specifications

- **Format**: SVG preferred (scalable, small file size)
- **Fallback**: PNG with transparent background
- **Size**: Minimum 500x500px for PNG
- **Color**: Should work on both light and dark backgrounds
- **File Size**: Keep under 50KB for optimal performance
